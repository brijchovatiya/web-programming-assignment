About Me

I used to think a webpage was finished as soon as it looked right. Now I know I should click every link, open every page, and check that each image loads before I share it.

A small typo in a file name can break a link even when the rest of the code is correct. I had to pay attention to spelling and make sure the HTML files and image folder stayed together.

If I made a website for a real customer, I would also ask them to review the wording and test it on their phone. A website should make sense to the person using it, not only to the person who built it.
