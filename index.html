About Me

I started learning web programming because I want a skill I can use for a side hustle. My first goal is to build simple websites for people or small businesses that need a basic online presence.

When I opened my first HTML file, the page looked very plain, but seeing my own heading appear in the browser was still exciting. Adding links and images made it feel like an actual website instead of a blank document.

What I like most is that I can see the result right away. I change a line of code, refresh the browser, and find out whether it worked. Even small mistakes teach me something.

Websites I Would Like to Build

  • A simple website for a restaurant or food truck
  • A personal portfolio for a student or job seeker
  • An information page for a local event
