About Me

Hello, I am Brij

My name is Brij Chovatiya, and I am a Computer Science student with a minor in Actuarial Science at Georgia State University. I created this website as a practical way to improve my understanding of HTML and CSS.

I was motivated to learn web programming because it is a useful skill that could help me create a side hustle. I would like to build simple websites for students, local businesses, restaurants, and other people who need an online presence.

Web programming interests me because I can see the result of my work immediately. I can change the code, refresh the browser, and observe how the page changes. This makes the learning process creative as well as technical.

Creating this website has helped me practice page structure, navigation, images, color choices, and external stylesheets. As I learn more, I hope to build websites that are attractive, useful, and easy for visitors to navigate.
